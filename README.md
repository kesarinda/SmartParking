# 🚗 SmartParking – Smart Parking Reservation System

SmartParking is a web-based parking reservation system that allows users to view available parking slots and reserve parking spaces online.

The application also supports installation on Android devices as a Progressive Web App (PWA).

## 🌐 Live Demo

[Open SmartParking](https://smartparking-e4oq.onrender.com)

## ✨ Features

- View available parking lots and parking slots.
- Check parking slot availability.
- Reserve parking slots online.
- Backend integration with a database.
- Responsive web interface.
- Installable on Android devices using Chrome.
- Custom PWA app icons.
- Web App Manifest and Service Worker support.
- Standalone app experience.

## 🛠️ Technologies Used

**Backend**
- Java
- Spring Boot
- Spring Data JPA
- Hibernate

**Frontend**
- HTML
- CSS
- JavaScript

**Database**
- TiDB (MySQL compatible)

**Deployment**
- Render
- Docker
- GitHub

**PWA**
- Web App Manifest
- Service Worker
- Custom app icons

## 📱 Progressive Web App

SmartParking can be installed on Android devices through Google Chrome.

PWA features include:
- 192×192 and 512×512 app icons.
- Standalone display mode.
- Service Worker registration.
- Basic static asset caching.

**Note:** Internet access is required for parking availability and booking operations.

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/kesarinda/SmartParking.git
```

2. Open the project in your IDE.

3. Configure your database connection in the application properties.

4. Run the Spring Boot application:

```bash
mvn spring-boot:run
```

5. Open your browser:

```text
http://localhost:8080
```
